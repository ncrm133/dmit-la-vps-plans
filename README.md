## 三条线路，差的不是配置而是回程

T1 是国际优化线路接中国大陆普通线路，端口给到 4Gbps 到 10Gbps，月流量 1TB 到 8TB。这个端口不是为国内访问准备的，它的用处在大流量搬运：镜像、备份、文件分发、爬虫、给海外用户提供 API。国内打开的速度和普通美国机房没有区别，别指望它解决晚高峰。

EB 走三网 CMIN2 直连，移动方向最优，电信和联通也走优化回程。它和 Pro 同价，月流量却普遍多出 50% 到 100%：TINY 是 1.5TB 对 1TB，STARTER 是 5TB 对 3TB，MEDIUM 是 30TB 对 14TB，GIANT 直接翻倍到 100TB。

Pro 走三网 CN2 GIA 直连。CN2 GIA 是中国电信的优质承载网，回程质量在三家运营商里最稳，成本也最高。DMIT 把它做成了和 EB 同价、只减流量的形式，所以入门门槛没有想象中高：一杯咖啡的月付价，买的是三网 CN2 GIA 的回程。

端口这一项容易看漏。Pro 和 EB 的 TINY 只给 1Gbps，从 Pocket 起是 4Gbps，STARTER 起才到 10Gbps。T1 的入门款就有 4Gbps。端口大小影响突发下载和并发能力，不影响单线程的国内访问延迟，别为了端口数字去升级套餐。

三张表里都有一列“超量后”，这是 DMIT 比较少见的处理方式：流量跑完不停机，降速继续用。降速幅度按线路分得很开，T1 是 100Mbps 到 200Mbps，Pro 和 EB 只有 4Mbps 到 10Mbps。同样标着不限量，T1 超量后还能当一台正常落地机跑，Pro TINY 超量后基本只够维持 SSH 和轻量网页。打算买 Pro 或 EB 的人，先按自己的月流量选档，别把它当无限流量套餐用。

## 什么人不需要 DMIT

只想要一台最便宜的洛杉矶落地机、不在乎回程质量，DMIT 不是最优解。T1.WEE 的 $36.90/年 买的是 4Gbps 端口和 100Mbps 的超量带宽，配置本身只有 1核1G，同样的钱在别处能买到更大的内存。

核心需求是原生 IP 或双 ISP 属性的，也得先确认。DMIT 的公开套餐说明里没有把 IP 属性当卖点，做跨境电商、账号矩阵之前先问客服，别默认。市场上确实有商家把这类 IP 单独做成产品线，比如 ZgoCloud 的双 ISP 系列，代价是它自己在产品说明里写明的：中国到洛杉矶方向不做路由优化，为了维持 ISP 属性。IP 纯净和回程速度经常没法同时拿满，这个取舍要提前想清楚。

月流量超过套餐额度很多、又不愿意降速的，别买 Pro 和 EB。超量后 4Mbps 到 10Mbps 只能维持基本连通，跑视频、跑更新、跑同步都会很难受。这类用途应该直接上 T1，超量后还有 100Mbps 到 200Mbps。

需要 Windows、大硬盘、高防的，DMIT 这份价目表里都没有对应产品，不用在这里耗时间。

## 常见问题

**洛杉矶 VPS 晚高峰会不会掉速？**

看你买的是哪条线。T1 不优化中国方向，晚高峰走普通国际出口，体验取决于你当地的宽带出口质量。Pro 和 EB 的卖点就是回程优化，CN2 GIA 和 CMIN2 的意义主要体现在这里。具体延迟和丢包本文没有实测数据，不给数字。

**流量用超了会直接停机吗？**

不会，降速继续用。降多少看线路和套餐：T1 是 100Mbps 到 200Mbps，Pro 和 EB 是 4Mbps 到 10Mbps。买之前把这一列看清楚，比看流量数字本身更重要。

**Pro 和 EB 一个价，选哪个？**

电信宽带为主选 Pro，CN2 GIA 的回程对电信最友好。移动为主选 EB，CMIN2 本来就是移动的国际网络。联通两边都能用，看哪个档位的流量更贴合你的用量。拿不准就先月付一个月，$9.99 试错成本不高。

**年付还是月付？**

TINY 直接年付，省 25.8%，没有犹豫的必要。Pocket 及以上年付只省 10% 左右，先月付一个月验证线路更稳妥。T1 的 STARTER 和 MINI 年付没有折扣，更没必要一次付一年。

本文没有核验到当前有效的公开优惠码，不写不确定的东西。价目表上的年付价本身已经是折扣后的周期价。
